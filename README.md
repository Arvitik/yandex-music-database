# База данных музыкального сервиса «Яндекс Музыка»

Учебный проект на PostgreSQL. 

База хранит пользователей, жанровые предпочтения, исполнителей, альбомы, песни, плейлисты, подписки, рекомендации и события. Реализованы связи многие ко многим, история прослушиваний, индивидуальные оценки, пересчёт рейтинга и рекомендации по предпочитаемому жанру.

## Файлы

- `schema.sql` - создание таблиц, индексов, функций, представлений и демонстрационных данных.
- `queries.sql` - все 16 запросов из отчёта и три дополнительные выборки.
- `Курсач по БД Яндекс Музыка.docx` - исходный отчёт.

## Запуск в pgAdmin

1. Создать пустую базу `yandex_music`.
2. Нажать правой кнопкой по базе и открыть редактор запросов.
3. Открыть `schema.sql` и выполнить целиком.
4. Открыть `queries.sql`, выделить нужный запрос и выполнить.

Схема создаётся один раз в пустой базе. Данные добавляются автоматически.
